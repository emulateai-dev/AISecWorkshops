# Flip attack

The **flip** attack uses **conversation history** and target behavior to “flip” or steer model outputs across turns—typically requires a **`PromptChatTarget`** and careful handling of messages.

**Concepts**

- Relies on **chat** semantics (history, system prompts).
- Useful to study **turn-by-turn** manipulation patterns in authorized evaluations.

**Workshop use**
