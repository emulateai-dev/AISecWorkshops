# Built-in datasets

PyRIT ships **many built-in datasets** for red-teaming experiments. Some seeds are bundled locally; others are fetched on demand (e.g. from Hugging Face) and cached.

Datasets are easiest to manage through **PyRIT memory** (query by harm category, provenance, dedupe), but you can also **load datasets directly** to explore them, then import into memory later.

**Official guide:** [Loading built-in datasets](https://azure.github.io/PyRIT/code/datasets/loading-datasets/)

Below you can **copy** the sample Python, run it in your own environment, or use **Run for me** to execute a safe default (list dataset names only — no bulk download).
